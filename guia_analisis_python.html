Vista panorámica del comercio exterior

groupby · agg · barras comparativas · línea de tiempo
Básico

Antes de profundizar, necesitamos una imagen general del dataset: ¿cuánto se importó y exportó? ¿en qué meses hay más actividad? El método groupby + agg de pandas es el equivalente Python del GROUP BY ... SUM() de SQL.

Concepto clave — groupby + agg

groupby('columna').agg(nueva_col=('col_origen','funcion')) agrupa filas por el valor de una columna y aplica funciones de resumen (sum, count, mean, nunique) a las demás columnas.

Python — análisis_1_vista_general.py 
# ============================================================
# Agrupamos la tabla por tipo de operación y calculamos
# totales para tener una primera vista del dataset
# ============================================================

resumen_comercio = (
    tabla_despachos
    .groupby('operacion')            # agrupar por IMPORTACION / EXPORTACION
    .agg(
        total_items        = ('item',      'count'),  # contar líneas
        valor_fob_dolares  = ('fob_dolar', 'sum'  ),  # sumar valor FOB
        peso_total_kg      = ('kilo_neto', 'sum'  ),  # sumar peso neto
        despachos_unicos   = ('despacho_cifrado', 'nunique'),
    )
    .reset_index()
    .sort_values('valor_fob_dolares', ascending=False)
)

# Convertimos a millones para que los números sean más legibles
resumen_comercio['fob_en_millones'] = (
    resumen_comercio['valor_fob_dolares'] / 1_000_000
)

# ---- Gráfico con dos paneles lado a lado ----

panel_izquierdo.set_title('Cantidad de ítems registrados')

# Panel derecho: valor FOB en millones
panel_derecho.bar(resumen_comercio['operacion'],

plt.show()

Principales socios comerciales

sort_values · head · barh horizontal · pivot_table · heatmap
Básico

Identificamos los países de los que más importa Paraguay y qué aduanas manejan más tráfico por mes. El gráfico de barras horizontal (barh) es preferible al vertical cuando los nombres son largos. El mapa de calor (heatmap) permite detectar patrones en una matriz de dos dimensiones.

¿Por qué barras horizontales?

Cuando las etiquetas del eje X son textos largos (nombres de países), barh() evita la rotación de texto y hace el gráfico más legible. El orden se invierte con [::-1] para que el mayor quede arriba.

Python — análisis_2_socios_comerciales.py 
# ---- Top 10 países de origen por valor FOB importado ----

Regla del 80/20 — Principio de Pareto

cumsum() · eje doble twinx() · líneas de referencia
Intermedio

El economista Vilfredo Pareto observó que el 20% de las causas explican el 80% de los efectos. En comercio exterior: un grupo pequeño de productos concentra la mayoría del valor comerciado. Este análisis es fundamental para priorizar controles aduaneros y negociaciones.

Concepto clave — cumsum()

La suma acumulada (cumsum()) transforma una lista de porcentajes individuales en una curva que crece de 0 a 100. El punto donde cruza el 80% nos dice cuántos rubros necesitamos para cubrir la mayor parte del valor. Ejemplo: [10, 25, 30, 20, 15] → cumsum → [10, 35, 65, 85, 100]

Python — análisis_3_pareto_80_20.py 
# ============================================================
# Calculamos el valor FOB por rubro y el porcentaje acumulado
# ============================================================
fob_agrupado_por_rubro = (
    solo_importaciones
    .dropna(subset=['rubro'])
    .groupby('rubro')['fob_dolar']
    .sum()
    .sort_values(ascending=False)   # mayor a menor es obligatorio para Pareto
    .reset_index()
)
fob_agrupado_por_rubro.columns = ['rubro', 'fob_total']

valor_total_general = fob_agrupado_por_rubro['fob_total'].sum()

# Porcentaje que representa cada rubro sobre el total
fob_agrupado_por_rubro['porcentaje_individual'] = (
    fob_agrupado_por_rubro['fob_total'] / valor_total_general * 100
)

# cumsum(): suma acumulada → construye la curva de Pareto
fob_agrupado_por_rubro['porcentaje_acumulado'] = (
    fob_agrupado_por_rubro['porcentaje_individual'].cumsum()
)

# ¿Cuántos rubros necesitamos para llegar al 80% del valor?
cantidad_rubros_para_80_pct = (
    fob_agrupado_por_rubro['porcentaje_acumulado'] <= 80
).sum() + 1
total_de_rubros = len(fob_agrupado_por_rubro)

print(f'Rubros que concentran el 80% del valor: {cantidad_rubros_para_80_pct}')
print(f'Total de rubros distintos:              {total_de_rubros}')
print(f'Concentración: {cantidad_rubros_para_80_pct/total_de_rubros*100:.1f}% de rubros = 80% del valor')

# ---- Diagrama de Pareto con eje doble ----
# twinx() crea un segundo eje Y a la derecha del mismo gráfico
figura, eje_barras = plt.subplots(figsize=(14, 6))
eje_curva_acumulada = eje_barras.twinx()

# Barras: valor FOB por rubro (eje izquierdo)
eje_barras.bar(
    range(len(fob_agrupado_por_rubro)),
    fob_agrupado_por_rubro['fob_total'] / 1_000_000,
    color='#0053a0',
    alpha=0.75,
    label='FOB por rubro'
)

# Línea: porcentaje acumulado (eje derecho)
eje_curva_acumulada.plot(
    range(len(fob_agrupado_por_rubro)),
    fob_agrupado_por_rubro['porcentaje_acumulado'],
    color='#e87132',
    linewidth=2.5,
    label='% acumulado'
)

# Línea punteada de referencia al 80%
eje_curva_acumulada.axhline(y=80, color='gray', linestyle='--', linewidth=1.2)
eje_barras.axvline(x=cantidad_rubros_para_80_pct - 0.5, color='gray', linestyle='--')

eje_barras.set_title('Diagrama de Pareto — Valor FOB por rubro de importación')
eje_barras.set_ylabel('Millones de USD')
eje_curva_acumulada.set_ylabel('Porcentaje acumulado (%)')
eje_curva_acumulada.set_ylim(0, 110)
plt.tight_layout()
plt.show()
cumsum() Suma acumulada. Transforma valores individuales en una curva creciente de 0 a 100%.
twinx() Crea un segundo eje Y a la derecha del gráfico para superponer dos escalas distintas.
axhline / axvline Dibuja líneas de referencia horizontales y verticales sobre el gráfico.

¿Cuánto cuesta realmente importar? — Composición del CIF

fillna(0) · barras apiladas con bottom= · comparación por transporte
Intermedio

El precio FOB es solo una parte del costo real de una importación. El valor que la aduana usa como base para calcular los tributos es el CIF, que incluye el flete y el seguro. Este análisis muestra cómo varía esa composición según el medio de transporte.

CIF  =  FOB  +  Flete  +  Seguro   |   Cost, Insurance and Freight

¿Por qué usar fillna(0)?

No todos los despachos declaran flete o seguro. Si sumamos sin tratar los nulos, NaN + 100 = NaN y perderíamos esa fila. fillna(0) reemplaza los nulos por cero antes de sumar, asumiendo que el flete/seguro está incluido en el FOB o no fue declarado.

Python — análisis_4_composicion_cif.py 
# ============================================================
# Calculamos el CIF para cada ítem sumando los tres componentes
# ============================================================
tabla_con_cif = solo_importaciones.copy()

tabla_con_cif['valor_cif_dolar'] = (
    tabla_con_cif['fob_dolar']                  # valor en origen
    + tabla_con_cif['flete_dolar'].fillna(0)  # si no hay flete → 0
    + tabla_con_cif['seguro_dolar'].fillna(0) # si no hay seguro → 0
)

# Agrupamos los componentes por medio de transporte
cif_por_medio_transporte = (
    tabla_con_cif
    .dropna(subset=['medio_transporte'])
    .groupby('medio_transporte')
    .agg(
        monto_fob    = ('fob_dolar',    'sum'),
        monto_flete  = ('flete_dolar',  'sum'),
        monto_seguro = ('seguro_dolar', 'sum'),
    )
    .reset_index()
    .sort_values('monto_fob', ascending=False)
)

# Convertimos a millones para el gráfico
fob_m    = cif_por_medio_transporte['monto_fob']    / 1_000_000
flete_m  = cif_por_medio_transporte['monto_flete']  / 1_000_000
seguro_m = cif_por_medio_transporte['monto_seguro'] / 1_000_000

figura, eje = plt.subplots(figsize=(10, 5))
posiciones = range(len(cif_por_medio_transporte))

# Barras APILADAS: cada segmento parte desde donde terminó el anterior
# El parámetro bottom= indica la altura de la base de cada barra
eje.bar(posiciones, fob_m,                           color='#0053a0', label='FOB')
eje.bar(posiciones, flete_m,  bottom=fob_m,            color='#0d9ed5', label='Flete')
eje.bar(posiciones, seguro_m, bottom=fob_m + flete_m,  color='#bacbe6', label='Seguro')

eje.set_xticks(posiciones)
eje.set_xticklabels(cif_por_medio_transporte['medio_transporte'], rotation=15)
eje.set_title('Composición del valor CIF por medio de transporte')
eje.set_ylabel('Millones de USD')
eje.legend()
plt.tight_layout()
plt.show()
fillna(0) Reemplaza valores nulos por cero. Evita que NaN contamine los resultados de sumas.
Barras apiladas (bottom=) El parámetro bottom= coloca cada nueva barra sobre la anterior para mostrar composición.
CIF vs FOB CIF incluye flete y seguro. Es la base tributaria usada por la aduana para calcular impuestos.
copy() Crear una copia del DataFrame para no modificar el original al agregar columnas nuevas.

¿Quién paga más impuestos? — Carga tributaria por rubro

Tasa efectiva ponderada · barh con colores condicionales
Intermedio

No todos los productos pagan la misma proporción de impuestos. Calculamos la tasa tributaria efectiva de cada rubro: qué porcentaje del valor imponible se paga en tributos. Este indicador es más representativo que el promedio de tasas individuales porque pondera por el valor de cada ítem.

Tasa efectiva (%)  =  (Derecho + ISC + IVA + Otros)  ÷  Valor Imponible  × 100

¿Por qué calcular sobre totales y no promediar tasas?

Un ítem de USD 1 con 50% de tasa no debería pesar igual que uno de USD 1.000.000. Al agrupar primero los montos y recién entonces dividir, los ítems de mayor valor tienen más influencia en el resultado final. Esto se llama promedio ponderado.

Python — análisis_5_carga_tributaria.py 
# Solo analizamos importaciones con valor imponible declarado
importaciones_gravadas = solo_importaciones[
    solo_importaciones['imponible_dolar'] > 0
].copy()

# Sumamos todos los tributos en una sola columna nueva
importaciones_gravadas['total_tributos_pagados'] = (
    importaciones_gravadas['derecho'].fillna(0) +
    importaciones_gravadas['isc'].fillna(0)     +
    importaciones_gravadas['iva'].fillna(0)     +
    importaciones_gravadas['otros'].fillna(0)
)

# Agrupamos por rubro y calculamos los montos totales
carga_agrupada_por_rubro = (
    importaciones_gravadas
    .dropna(subset=['rubro'])
    .groupby('rubro')
    .agg(
        base_imponible_total = ('imponible_dolar',       'sum'),
        tributos_totales     = ('total_tributos_pagados', 'sum'),
        cantidad_items       = ('item',                   'count'),
    )
    .reset_index()
)

# La tasa efectiva se calcula sobre los totales del rubro (no promedio de tasas)
carga_agrupada_por_rubro['tasa_efectiva_pct'] = (
    carga_agrupada_por_rubro['tributos_totales']
    / carga_agrupada_por_rubro['base_imponible_total']
    * 100
)

top_15_rubros_mas_gravados = (
    carga_agrupada_por_rubro
    .sort_values('tasa_efectiva_pct', ascending=False)
    .head(15)
)

figura, eje = plt.subplots(figsize=(10, 7))

# Color condicional: rojo si tasa > 30%, azul si tasa ≤ 30%
colores_condicionales = [
    '#a02b93' if tasa > 30 else '#0053a0'
    for tasa in top_15_rubros_mas_gravados['tasa_efectiva_pct'][::-1]
]

eje.barh(
    top_15_rubros_mas_gravados['rubro'].str[:40][::-1],
    top_15_rubros_mas_gravados['tasa_efectiva_pct'][::-1],
    color=colores_condicionales
)
eje.set_title('Top 15 rubros con mayor carga tributaria efectiva')
eje.set_xlabel('Tasa efectiva = tributos / valor imponible (%)')
plt.tight_layout()
plt.show()
Color condicional Colorear barras según una condición: 'rojo' if tasa > 30 else 'azul' aplicado en una lista por comprensión.
Tasa efectiva ponderada Más representativa que el promedio de tasas. Refleja el verdadero impacto fiscal del rubro.
.str[:40] Truncar texto largo en pandas para que las etiquetas quepan en el gráfico.
ISC / Derecho / IVA Tres tributos principales: arancel aduanero, impuesto selectivo al consumo e IVA.

¿Beneficia el MERCOSUR a Paraguay? — Test estadístico

scipy.stats.mannwhitneyu · hipótesis nula · box plot comparativo
Intermedio

Para afirmar que el MERCOSUR reduce las tasas arancelarias con rigor científico, no basta comparar promedios. Necesitamos un test estadístico que nos diga si la diferencia observada es real o podría ocurrir por azar. Usamos el test de Mann-Whitney U porque las tasas no tienen distribución normal (hay muchos ceros y valores extremos).

Hipótesis estadística

H₀ (nula): No hay diferencia entre las tasas de MERCOSUR y SIN ACUERDO.
H₁ (alternativa): Hay una diferencia significativa entre ambos grupos.
Si el valor p < 0.05, rechazamos H₀ y concluimos que la diferencia es real.

¿Por qué Mann-Whitney y no una prueba T?

La prueba T asume que los datos siguen una distribución normal. Las tasas arancelarias tienen muchos ceros (productos exentos) y algunos valores muy altos, por lo que no son normales. Mann-Whitney es un test no paramétrico: compara distribuciones sin hacer suposiciones sobre su forma.

Python — análisis_6_impacto_mercosur.py 
from scipy.stats import mannwhitneyu

# Calculamos la tasa de derecho efectiva para cada ítem
importaciones_con_acuerdo = solo_importaciones[
    (solo_importaciones['imponible_dolar'] > 0) &
    (solo_importaciones['acuerdo'].notna())
].copy()

importaciones_con_acuerdo['tasa_derecho_pct'] = (
    importaciones_con_acuerdo['derecho'].fillna(0)
    / importaciones_con_acuerdo['imponible_dolar']
    * 100
)

# Separamos los dos grupos que vamos a comparar
tasas_grupo_mercosur    = importaciones_con_acuerdo[
    importaciones_con_acuerdo['acuerdo'] == 'MERCOSUR'
]['tasa_derecho_pct'].dropna()

tasas_grupo_sin_acuerdo = importaciones_con_acuerdo[
    importaciones_con_acuerdo['acuerdo'] == 'SIN ACUERDO'
]['tasa_derecho_pct'].dropna()

# Test Mann-Whitney U: compara las distribuciones de ambos grupos
estadistico_u, valor_p = mannwhitneyu(
    tasas_grupo_mercosur,
    tasas_grupo_sin_acuerdo,
    alternative='two-sided'   # comparamos en ambas direcciones
)

print(f'MERCOSUR     → n={len(tasas_grupo_mercosur):,}    mediana={tasas_grupo_mercosur.median():.2f}%')
print(f'SIN ACUERDO  → n={len(tasas_grupo_sin_acuerdo):,}  mediana={tasas_grupo_sin_acuerdo.median():.2f}%')
print(f'Estadístico U: {estadistico_u:,.0f}')
print(f'Valor p:       {valor_p:.6f}')

if valor_p < 0.05:
    print('→ Diferencia SIGNIFICATIVA (p < 0.05)')
    print('  El MERCOSUR tiene un efecto estadísticamente demostrable.')
else:
    print('→ Diferencia NO significativa (p ≥ 0.05)')
    print('  No hay evidencia suficiente para afirmar efecto del MERCOSUR.')
Mann-Whitney U Test no paramétrico para comparar dos grupos sin asumir distribución normal.
Valor p (p-value) Probabilidad de observar esa diferencia por azar. Si p < 0.05, la diferencia es significativa.
alternative='two-sided' Detecta diferencias en cualquier dirección: A mayor que B, o B mayor que A.
scipy.stats Módulo de Python para estadística: pruebas de hipótesis, distribuciones, correlaciones.

El semáforo aduanero — Canal de despacho

map() · sns.boxplot · set_yscale('log') · showfliers=False
Intermedio

Cada despacho recibe un canal que determina el nivel de control aduanero. Canal V (Verde) = liberación automática. Canal R (Rojo) = revisión física obligatoria. Analizamos si los despachos de cada canal difieren en valor, peso y tributos.

¿Qué es el box plot y cómo leerlo?

La caja contiene el 50% central de los datos (de Q1 a Q3). La línea dentro de la caja es la mediana (valor del 50%). Los bigotes llegan hasta 1.5 × IQR. Los puntos fuera son outliers. showfliers=False oculta esos puntos extremos para ver mejor la caja.

Python — análisis_7_canal_despacho.py 
# Filtramos solo los canales V (Verde) y R (Rojo)
despachos_por_canal = tabla_despachos[
    tabla_despachos['canal'].isin(['V', 'R'])
].copy()

# map() reemplaza cada código por su descripción legible
despachos_por_canal['nombre_del_canal'] = despachos_por_canal['canal'].map({
    'V': 'Verde (automático)',
    'R': 'Rojo (revisión física)'
})

figura, paneles = plt.subplots(1, 3, figsize=(14, 5))
figura.suptitle('Comparación de despachos por canal (Verde vs Rojo)')

variables_para_comparar = [
    ('fob_dolar',        'Valor FOB (USD)'),
    ('kilo_neto',        'Peso neto (kg)'),
    ('total_tributos',    'Total tributos (USD)'),
]

colores_canal = {
    'Verde (automático)':    '#196b24',
    'Rojo (revisión física)': '#b71c1c'
}

for panel, (nombre_variable, titulo_panel) in zip(paneles, variables_para_comparar):
    datos_positivos = despachos_por_canal[
        despachos_por_canal[nombre_variable] > 0
    ]
    sns.boxplot(
        data=datos_positivos,
        x='nombre_del_canal',
        y=nombre_variable,
        palette=colores_canal,
        width=0.45,
        showfliers=False,   # oculta outliers extremos para ver la caja
        ax=panel,
        order=['Verde (automático)', 'Rojo (revisión física)']
    )
    panel.set_title(titulo_panel)

Perfiles de países — Agrupamiento K-Means + PCA

StandardScaler · KMeans · PCA · scatter plot etiquetado
Avanzado

El clustering es aprendizaje automático no supervisado: le damos los datos y el algoritmo encuentra grupos similares por sí solo. K-Means agrupa los países según su perfil comercial. Luego usamos PCA para reducir 5 variables a 2 dimensiones y poder visualizar los grupos en un plano.

¿Por qué normalizar antes de agrupar?

K-Means mide distancias entre puntos. Si no normalizamos, el FOB en miles de USD dominaría sobre variables pequeñas como diversidad de rubros (un número entre 1 y 30). StandardScaler lleva todas las variables a media = 0 y desviación estándar = 1, equiparando su influencia.

¿Qué es PCA?

El Análisis de Componentes Principales (Principal Component Analysis) busca las combinaciones lineales de variables que capturan la mayor varianza posible. Reduce N dimensiones a 2 para poder graficar, preservando la mayor cantidad de información.

Python — análisis_8_clustering_paises.py 
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# ---- PASO 1: Construir el perfil de cada país ----
MIN_ITEMS_POR_PAIS = 5   # excluir países con muy pocos datos

perfil_por_pais = (
    solo_importaciones
    .dropna(subset=['pais_origen'])
    .groupby('pais_origen')
    .agg(
        total_items          = ('item',      'count'),
        fob_promedio         = ('fob_dolar', 'mean'),
        peso_promedio_kg     = ('kilo_neto', 'mean'),
        flete_promedio       = ('flete_dolar', 'mean'),
        rubros_distintos     = ('rubro',     'nunique'),
        porcentaje_mercosur  = ('acuerdo',
                                lambda x: (x == 'MERCOSUR').mean() * 100),
    )
    .reset_index()
)
perfil_por_pais = perfil_por_pais[
    perfil_por_pais['total_items'] >= MIN_ITEMS_POR_PAIS
].copy()

# ---- PASO 2: Normalizar las variables ----
columnas_para_clustering = [
    'fob_promedio', 'peso_promedio_kg', 'flete_promedio',
    'rubros_distintos', 'porcentaje_mercosur'
]
valores_a_normalizar = perfil_por_pais[columnas_para_clustering].fillna(0).values

normalizador       = StandardScaler()   # media=0, desvío=1 por variable
valores_normalizados = normalizador.fit_transform(valores_a_normalizar)

# ---- PASO 3: K-Means — encontrar grupos de países similares ----
CANTIDAD_DE_GRUPOS = 3   # elegir según el método del codo

modelo_agrupamiento       = KMeans(n_clusters=CANTIDAD_DE_GRUPOS, random_state=42, n_init=10)
perfil_por_pais['grupo']  = modelo_agrupamiento.fit_predict(valores_normalizados)

# ---- PASO 4: PCA — reducir a 2 dimensiones para graficar ----
reductor_a_2d        = PCA(n_components=2, random_state=42)
coordenadas_2d       = reductor_a_2d.fit_transform(valores_normalizados)
perfil_por_pais['eje_x'] = coordenadas_2d[:, 0]
perfil_por_pais['eje_y'] = coordenadas_2d[:, 1]

varianza_preservada = reductor_a_2d.explained_variance_ratio_.sum() * 100
print(f'PCA preservó el {varianza_preservada:.1f}% de la información original')

# ---- PASO 5: Visualizar los grupos en 2D ----
paleta_grupos = ['#0053a0', '#e87132', '#0b6967']
figura, eje = plt.subplots(figsize=(11, 7))

for numero_grupo in range(CANTIDAD_DE_GRUPOS):
    mascara_grupo = perfil_por_pais['grupo'] == numero_grupo
    datos_grupo   = perfil_por_pais[mascara_grupo]
    eje.scatter(
        datos_grupo['eje_x'],
        datos_grupo['eje_y'],
        s=datos_grupo['total_items'] * 2,  # tamaño ∝ volumen del país
        color=paleta_grupos[numero_grupo],
        alpha=0.75,
        label=f'Grupo {numero_grupo}'
    )

# Etiquetamos solo los países de mayor volumen
paises_mas_importantes = perfil_por_pais.nlargest(8, 'total_items')
for _, fila in paises_mas_importantes.iterrows():
    eje.annotate(fila['pais_origen'][:20], (fila['eje_x'], fila['eje_y']),
                xytext=(6, 4), textcoords='offset points', fontsize=8)

eje.set_title(
    f'Agrupamiento de países por perfil comercial ({CANTIDAD_DE_GRUPOS} grupos)\n'
    f'Reducción PCA — {varianza_preservada:.1f}% de información preservada'
)
eje.legend()
plt.tight_layout()
plt.show()
StandardScaler Normaliza variables a media=0 y desvío=1. Obligatorio antes de K-Means.
KMeans.fit_predict() Entrena el modelo y asigna un número de grupo a cada fila en un solo paso.
PCA(n_components=2) Reduce N variables a 2 componentes para poder graficar los grupos en un plano.

Detectar valores inusuales — Método IQR

def · quantile() · groupby transform() · detección por rubro
Avanzado

La subvaloración (declarar un precio FOB menor al real) es el principal mecanismo de evasión fiscal aduanera. Una señal de alerta es un precio por kilogramo inusualmente bajo para su rubro. El método IQR detecta estos valores sin necesidad de conocer el precio "correcto" de cada mercadería.

IQR = Q3 − Q1  |  Límite inferior = Q1 − 1.5 × IQR  |  Límite superior = Q3 + 1.5 × IQR

¿Por qué detectar dentro de cada rubro?

El precio por kilogramo de algodón en rama no es comparable con el de un perfume o un medicamento. Si aplicáramos el IQR al dataset completo, los precios bajos de materias primas serían marcados como anomalías. Al aplicarlo dentro de cada rubro, comparamos manzanas con manzanas.

Python — análisis_9_deteccion_anomalias.py 
# ============================================================
# Calculamos el precio por kilogramo como indicador de valoración
# ============================================================
importaciones_con_peso = solo_importaciones[
    (solo_importaciones['kilo_neto']  > 0) &
    (solo_importaciones['fob_dolar']  > 0) &
    (solo_importaciones['rubro'].notna())
].copy()

importaciones_con_peso['precio_por_kg'] = (
    importaciones_con_peso['fob_dolar'] / importaciones_con_peso['kilo_neto']
)

# ---- Definimos la función de detección IQR ----
# Recibe una serie de precios y devuelve True donde el precio es inusual
def detectar_precio_inusual_iqr(serie_de_precios):
    cuartil_inferior = serie_de_precios.quantile(0.25)   # Q1: el 25% más bajo
    cuartil_superior = serie_de_precios.quantile(0.75)   # Q3: el 75% más bajo
    rango_intercuartilico = cuartil_superior - cuartil_inferior

    precio_limite_inferior = cuartil_inferior - (1.5 * rango_intercuartilico)
    precio_limite_superior = cuartil_superior + (1.5 * rango_intercuartilico)

    # Retorna True si el precio está FUERA del rango normal
    return (
        (serie_de_precios < precio_limite_inferior) |
        (serie_de_precios > precio_limite_superior)
    )

# ---- Aplicamos la función DENTRO de cada rubro ----
# transform() aplica una función grupo por grupo y devuelve
# una serie del mismo tamaño que el DataFrame original
importaciones_con_peso['precio_es_inusual'] = (
    importaciones_con_peso
    .groupby('rubro')['precio_por_kg']
    .transform(detectar_precio_inusual_iqr)
)

total_anomalias  = importaciones_con_peso['precio_es_inusual'].sum()
porcentaje_total = total_anomalias / len(importaciones_con_peso) * 100
print(f'Ítems con precio inusual: {total_anomalias:,} ({porcentaje_total:.1f}%)')

# ---- Los 10 despachos de mayor valor con precio inusual ----
# Son los más relevantes para una auditoría real
alertas_ordenadas_por_valor = importaciones_con_peso[
    importaciones_con_peso['precio_es_inusual']
].sort_values('fob_dolar', ascending=False)

columnas_para_reporte = [
    'despacho_cifrado', 'rubro', 'pais_origen',
    'fob_dolar', 'kilo_neto', 'precio_por_kg', 'aduana'
]
print(alertas_ordenadas_por_valor[columnas_para_reporte].head(10).to_string(index=False))

Importante — anomalía estadística ≠ fraude confirmado

Un precio inusual es una señal de alerta, no una conclusión definitiva. Puede deberse a mercadería de calidad excepcional, lotes pequeños, cargamentos de muestra o errores de tipeo. Es el punto de partida para una revisión más profunda, no la prueba del delito.
